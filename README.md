# RP Core — Discord-бот для РП-проекта

Администрация, РП-составляющая (профили, заявки, составы, кадры, документы, бюджет), тикеты, музыка — и
**веб-админ-панель**, где настраивается всё. Те же основные настройки доступны командой `/setting`.

## Запуск за 10 минут
1. [Discord Developer Portal](https://discord.com/developers/applications) → New Application → **Bot** → Reset Token.
   Включите **Server Members Intent** и **Message Content Intent**.
2. **OAuth2** → скопируйте Client ID и Client Secret. В **Redirects** добавьте `BASE_URL/callback`
   (локально: `http://localhost:8080/callback`).
3. `cp .env.example .env` и заполните `DISCORD_TOKEN`, `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`, `BASE_URL`,
   `SECRET_KEY` (любая длинная строка), `OWNER_IDS` (ваш Discord ID).
4. `pip install -r requirements.txt python-dotenv`, на сервере нужен **ffmpeg** (для музыки).
5. `python run.py`
6. Добавьте бота на сервер (ссылка есть в панели, если у вас нет серверов) и дайте ему роль выше ролей, которые он выдаёт.
   Для проверки команд на одном сервере сразу укажите `DEV_GUILD_ID` (глобально команды появляются до часа).
7. Откройте панель → **Обзор** покажет, что осталось настроить → Конструктор → **Панели** → «Опубликовать».

## Что внутри
| Раздел | Команды / где настраивается |
|---|---|
| Профиль (ФИО + Статик), личный кабинет | кнопки панелей, `/cabinet`; шаблоны проверки — Настройки → Профиль |
| Заявки и обращения (формы, ветки, роли при одобрении) | Конструктор → Формы |
| Панели с кнопками (до 25, ссылки, живое превью) | Конструктор → Панели, `/panel publish` |
| Составы, кадры, личное дело | Конструктор → Должности; `/hr hire\|transfer\|fire\|history`, `/roster`, `/file` |
| Документы и бюджет | `/doc issue\|list\|delete`, `/budget income\|expense\|report` |
| Модерация и автомодерация, логи | `/ban /kick /timeout /warn /warns /cases /purge /lock`; Настройки → Модерация, Логи |
| Тикеты с транскриптами | Конструктор → Категории тикетов |
| Музыка | `/play /pause /skip /stop /queue /loop /volume /shuffle`; Настройки → Музыка |
| Приветствие, авто-роли | Настройки → Приветствие |
| Кадровый аудит (принятие / повышение / понижение / увольнение) — сообщение без заявки | кнопка панели «Кадровый аудит»; варианты, цвета и канал — Конструктор → Формы → «Кадровый аудит» |
| Автоматическое создание каналов (с откатом) | `/setup create`, `/setup undo` или веб-панель → Автонастройка каналов |
| Новости | `/news` (с картинкой и пингом роли) и веб-панель → Отправить новость |
| Что включено / что работает | `/status`; включение и выключение модулей — `/setting` → Модули или веб-панель |

Кнопки в панелях работают и после перезапуска бота. Действие кнопки: форма, тикет, личный кабинет, личное дело, составы или ссылка.

## Бесплатный хостинг без банковской карты (Render + резервные копии в Discord)
Бесплатные хостинги стирают диск при перезапуске. Поэтому бот сам раз в 30 минут (если что-то менялось) кладёт сжатую копию
базы в приватный канал Discord и при запуске с пустым диском восстанавливает последнюю. Для этого нужен `BACKUP_CHANNEL_ID`.

1. Создайте на сервере **приватный канал** (например `#бэкапы-бота`), дайте боту: просмотр канала, отправку сообщений, файлы, управление сообщениями.
   Скопируйте ID канала (ПКМ → Копировать ID) в `BACKUP_CHANNEL_ID`.
2. Загрузите проект на **GitHub** (аккаунт бесплатный, репозиторий может быть приватным). **Файл `.env` не загружать.**
3. **render.com** → New → Web Service → подключите репозиторий → Runtime **Docker** → Instance Type **Free**.
   В Environment добавьте переменные из `.env.example` (токен, Client ID/Secret, `SECRET_KEY`, `OWNER_IDS`, `BACKUP_CHANNEL_ID`).
   `BASE_URL` = адрес сервиса на Render (`https://имя.onrender.com`), и этот же `…/callback` добавьте в Redirects в Developer Portal.
4. Бесплатный сервис Render засыпает через 15 минут без обращений к сайту. Заведите бесплатный монитор на **uptimerobot.com**:
   HTTP(s) → `https://имя.onrender.com/health` → интервал 5 минут. Бот также сам обращается к этому адресу (`KEEPALIVE=1`).
5. Команда `/backup` (только владелец) делает копию немедленно, `/status` показывает, что включено и что не настроено.

Ограничения бесплатного тарифа: мало памяти и процессора — **музыка может заикаться или не работать** (плюс YouTube часто блокирует
IP хостингов); после внезапного сбоя теряются изменения за последние минуты (с последней копии).

Другие варианты: Oracle Cloud Always Free (нужна карта; скрипты `deploy/setup.sh` и `deploy/https.sh`), bot-hosting.net
(без карты, продление раз в 4 дня), свой компьютер.
Docker: `docker build -t rpbot . && docker run --env-file .env -p 8080:8080 -v $PWD/data:/app/data rpbot`

## Права бота
Проще выдать «Администратор». Минимум: управление ролями, каналами, ветками, участниками (бан/кик/тайм-аут),
сообщениями, просмотр аудита, подключение и речь в голосовых каналах.

## Кнопки панелей
В разделе «Панели» у каждой кнопки выбирается действие: открыть форму, открыть тикет, личный кабинет, личное дело, составы,
выдать/снять роль, ответить текстом или открыть ссылку. Изменения сразу обновляют сообщение в Discord.
Роли с административными правами кнопкой выдавать нельзя. Поле формы может быть выпадающим списком.

## Музыка
Команда `/musiccheck` показывает, чего не хватает (ffmpeg, PyNaCl, davey, opus, JS-среда для YouTube). В Docker-образе всё уже есть.
